# KeyDebounce

[English](README.en.md)

KeyDebounce 是一个 Windows 键盘消抖工具。机械键盘按一次却打出两个字母、空格或标点时，它可以过滤松手后紧接着出现的同键输入。

**[前往 Releases 下载 Windows 安装包](https://github.com/lehaifeng000-tools/keydebounce/releases/latest)**（在 **Assets** 中选择 `KeyDebounceSetup.msi`）

已在 64 位 Windows 11 上验证。

## 开发背景

我用的是有线连接的 CHERRY MX 8.2 银轴键盘。刚开始使用时一切正常，用了一段时间后，`R`、空格和逗号偶尔按一下就输入两次，后来越来越频繁。比如用拼音输入“如果今天”时，开头本来只按了一次 `R`，输入法却收到了两个 `r`。

为了继续用这把键盘，我做了一个软件层的过滤器。它直接放行首次按下，只有在松开后很短时间内又收到同一个键的按下事件时，才拦截这次重复输入。整个过程无需安装键盘驱动、刷写固件或更改 Windows 的键盘设置。

## 安装和使用

1. 下载并双击 `KeyDebounceSetup.msi`。安装页默认勾选 **Start KeyDebounce when I sign in to Windows**（登录 Windows 时启动），可按需取消。点击 **Install** 确认安装。
2. 在开始菜单搜索 **KeyDebounce** 并打开。程序运行时，双击任务栏通知区域的键帽图标也能打开中文设置。
3. 先用默认的 **30 毫秒**，在记事本或平时使用的输入法里试按容易连键的键。设置页的「拦截次数（按键）」会显示本次运行拦截了哪些键。
4. 连键仍然出现时，可以逐步调长过滤间隔。如果正常的快速连按也被拦截，就缩短间隔。可设置范围为 **5–120 毫秒**。

默认过滤 **A–Z、空格、主键区 0–9 和常用标点**，包括逗号、句号、分号和引号。想覆盖退格、方向键或数字小键盘等，可勾选「全部按键」，该选项默认关闭。选中的按键和过滤间隔会自动保存，下次启动时恢复。登录自启可随时在软件里开关。

关闭设置窗口后，程序会继续在通知区域运行。可以通过托盘菜单暂停过滤或退出。需要卸载时，可点击设置里的「卸载…」，也可以再次运行同版本安装包，选择 **Remove**。卸载会移除登录启动项，保留已保存的过滤设置。

## 适用范围

- 过滤在当前 Windows 登录会话中生效，同样应用于接入的其他键盘。按住按键产生的系统连发会保留。
- 过滤靠松开到再次按下的时间来判断，正常的极快连按也可能落入这个间隔。轴体故障仍需清洁、维修或更换来解决。
- 程序在本机运行，无需联网。它只在内存中统计本次运行的拦截次数，不记录或上传输入内容。

## 从源码构建

在 64 位 Windows 上，用 PowerShell 在仓库目录运行以下命令。

```powershell
.\BuildInstaller.ps1
```

脚本使用 Windows 的 .NET Framework C# 编译器、`makecab.exe` 和 Windows Installer，在仓库根目录生成 `KeyDebounce.exe` 和 `KeyDebounceSetup.msi`。
